# NSL-KDD Dataset Models

This folder contains Binary and Multiclass Intrusion Detection models developed using the NSL-KDD dataset.

## Implemented Models
- Bidirectional Simple RNN
- Bidirectional LSTM
- Bidirectional GRU

## Features
- XGBoost Feature Selection
- Attention Mechanism
- SHAP Explainability
- Binary Classification
- Multiclass Classification
- Confusion Matrix Analysis

## Technologies Used
- TensorFlow / Keras
- Scikit-learn
- XGBoost
- SHAP
- Python
